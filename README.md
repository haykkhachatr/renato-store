# Renato — տղամարդկանց հագուստի խանութ

**Կենդանի հղում.** https://haykkhachatr.github.io/renato-store/ · **Կոդ.** https://github.com/haykkhachatr/renato-store

Եռալեզու (հայերեն · English · Русский) ժամանակակից առցանց խանութ՝ անիմացիաներով։ **Միայն տղամարդկանց հագուստ, առանց կոշիկի։** Մաքուր HTML/CSS/JS է, **առանց build-ի և առանց սերվերի**. կարելի է բացել անմիջապես `index.html`-ը կամ գործարկել `start.bat`-ը (բացվում է `http://localhost:8080/`)։

## 1. Ինչ կա կայքում

| Բաժին | Ինչ է անում |
|---|---|
| Բեռնման էկրան | Լոգոյի հայտնվելը + հաշվիչ (սեսիայի ընթացքում՝ մեկ անգամ) |
| Վերնագիր | Հայտարարության շերտ (3 հաղորդագրություն), մեգա-մենյու «Հագուստ» և «Աքսեսուարներ», որոնում, լեզու, ընտրյալներ, զամբյուղ; քաշվելիս թաքնվում է, վերադառնալիս՝ երևում |
| Գլխավոր էջ | **Մուգ կանաչ հերո** (բառերի մաս-մաս բացվելը, պարալաքս, մկնիկին հետևող կամարներ, պտտվող կնիք), մարքի (արագանում է scroll-ի հետ), **բենտո կատեգորիաներ** (5 խումբ), **«Ուշադրության կենտրոնում»** (գույնի/չափսի ընտրություն և ավելացում անմիջապես գլխավոր էջում), «Նոր ժամանումներ» ներդիրներով, **զեղչերի պաստառ**, **կպցված հորիզոնական լուքբուք**, **կտորների բաժին**, պատմություն, առավելություններ, բաժանորդագրություն, ֆուտեր |
| Կատալոգ | 5 խումբ (Վերնահագուստ, Տրիկոտաժ և հուդի, Վերնաշապիկներ և թի-շրթեր, Տաբատներ և ջինս, Աքսեսուարներ) + Նորույթներ/Հիթեր/Զեղչեր; ֆիլտրեր (տեսակ, չափս, գույն, գին, միայն զեղչով), դասավորում, ակտիվ ֆիլտրերի չիպեր, հասցեն պահպանվում է |
| Ապրանքի քարտ | Գույների swatch-եր (փոխվում է պատկերը), hover-ով երկրորդ տեսք, արագ ավելացում (չափսով), ընտրյալներ, hover-ում վերև բարձրանալը |
| Ապրանքի էջ | Պատկերասրահ (առջևից/հետևից/մանրամասն/գույնի պատմություն, hover-zoom), գույն, չափս, ակորդեոններ, «Լրացրեք կերպարը», «Վերջերս դիտած», բջջայինում՝ կպցված «Ավելացնել» գոտի |
| Զամբյուղ | Կողքից բացվող դարակ, քանակ, անվճար առաքման առաջընթաց, «թռչող» ավելացման անիմացիա |
| Պատվեր | Ձև + վալիդացիա, առաքման/վճարման ընտրություն, պրոմոկոդ, հաստատման էջ |
| Տեղեկատվական էջեր | Մեր մասին, չափսերի աղյուսակ + չափսի հաշվիչ, առաքում, վերադարձ, կոնտակտներ, գաղտնիություն, պայմաններ |

**Տեսականի (27 ապրանք).** բլեյզերներ, վերարկու, բաճկոններ, սվիտերներ, կարդիգան, հուդիներ, վերնաշապիկներ (այդ թվում՝ վանդակավոր), պոլո, թի-շրթեր, տաբատներ, ջինսեր, շորտ, գոտի, գուլպա, շարֆ, գլխարկներ, պայուսակ։

Մատչելիություն (a11y). ստեղնաշարով ամբողջությամբ աշխատում է, skip-link, focus trap դարակներում, `prefers-reduced-motion` ռեժիմում անիմացիաները անջատվում են, axe-core-ը 12 էջի վրա (հայերեն՝ 1440px, անգլերեն՝ 390px) խախտում չի գտել։

## 3. ⚠ Ինչը օրինակային է և պետք է փոխարինել

Սա **իրական խանութի տվյալներ չեն**, ես դրանք հորինել եմ՝ կայքը կենդանի ցույց տալու համար.

- **Բոլոր 27 ապրանքները** (անուններ, գներ, զեղչեր, կտորի կազմ, չափսեր, «վերջին N-ը»). `js/data.js`
- **Ապրանքների նկարները.** դրանք լուսանկարներ չեն, այլ կոդով գեներացված ոճավորված պատկերներ։ Իրական լուսանկարներ դնելու ձևը՝ ստորև (§5)։
- **Կոնտակտներ.** հեռախոս `+374 00 000 000`, `hello@renato.example`, WhatsApp `37400000000`, Telegram `renato_store`, հասցե «Աբովյան 1» և աշխատանքային ժամեր, սոցցանցերի հղումներ. `js/config.js`
- **Առաքման գներ** (Երևան 1 500 ֏, մարզեր 2 500 ֏, անվճար՝ 25 000 ֏-ից), **«14 օր վերադարձ»**, **«Վճարում ստանալիս»**, պրոմոկոդ **WELCOME10** (−10%). սրանք իմ ենթադրություններն են, ոչ ձեր քաղաքականությունը։
- **Չափսերի աղյուսակ և չափսի հաշվիչ.** ընդհանուր ստանդարտ արժեքներ են, ստուգեք ձեր իրական կտրվածքներով։
- **Տեքստերը** (պատմություն, առավելություններ, կտորների նկարագրություն, առաքում, վերադարձ, գաղտնիություն, պայմաններ). գրել եմ ես։ **Հայերենը և ռուսերենը անհրաժեշտ է ստուգել հայերենով/ռուսերենով խոսող մարդու կողմից**։ Իրավական էջերը նախնական սևագրեր են, ոչ իրավաբանական խորհուրդ։
- **Լուքբուքի «կերպարները»** (`LOOKS` data.js-ում), **գլխավոր էջի 3 կամարը** և **«Ուշադրության կենտրոնում»** ապրանքը (pages.js, `home()`).
- Կայքում դեռ երևում են դեղին «Նախնական տեքստ» նշումները։ Երբ տեքստերը փոխեք՝ `config.js`-ում դրեք `draftNotes: false`։

Ես միտումնավոր **չեմ ավելացրել «հաճախորդների կարծիքներ»** բաժին. հորինված կարծիքներ չպետք է հայտնվեն կայքում։ Երբ իրական կարծիքներ ունենաք՝ կարելի է ավելացնել։

## 4. Ինչպես փոխել

**Ապրանք ավելացնել/փոխել** (`js/data.js`, `P` ցանկ)

```js
{ slug: 'carlo', name: 'Carlo', type: 'coat', price: 94900, old: 0,
  colors: [c('charcoal'), c('camel')], sizes: SZ.suit, oos: ['46'],
  fabric: 'woolblend', fit: 'regular', care: 'dry', tags: ['new','best'], tint: 'slate' }
```
- `type` — `coat, blazer, jacket, sweater, cardigan, hoodie, shirt, polo, longsleeve, tee, trousers, jeans, shorts, scarf, beanie, cap, tote, belt, socks`։ Տեսակից ավտոմատ որոշվում է խումբը (կատեգորիան)։
- `old` — հին գին (եթե լրացված է, ցույց է տալիս «−N%» և հայտնվում է «Զեղչեր»-ում)
- `oos` — սպառված չափսեր; եթե բոլորն են սպառված՝ ապրանքը «Սպառված է»
- `tags` — `new` · `best` · `sale` · `last` («Վերջին N-ը»)
- Նոր գույն. `COLORS`-ում ավելացրեք hex-ը և `i18n.js`-ում՝ `col.<անուն>` տողը 3 լեզվով։ Վանդակավոր/գծավոր գույն՝ `c('checkgreen', { pat: 'check' })`։

**Տեքստեր.** `js/i18n.js`. յուրաքանչյուր տող `['բանալի', 'հայերեն', 'English', 'Русский']` է, ուստի թարգմանություն բաց թողնել հնարավոր չէ։

**Գույներ/տառատեսակներ.** `css/style.css`-ի սկզբի `:root`։

**Բեռնման էկրանը անջատել.** `config.js` → `loader: false`։

## 5. Իրական լուսանկարներ

Լուսանկարները դրեք `assets/products/` թղթապանակում և ապրանքին ավելացրեք `photos` դաշտը՝ **գույնի բանալիով**.

```js
{ slug: 'carlo', … colors: [c('charcoal'), c('camel')],
  photos: { camel: ['assets/products/carlo-camel-1.jpg', 'assets/products/carlo-camel-2.jpg', 'assets/products/carlo-camel-3.jpg'],
            charcoal: ['assets/products/carlo-charcoal-1.jpg'] } }
```
Հերթականությունը՝ 1 = առջևից, 2 = հետևից, 3 = մանրամասն։ Եթե նկարները 3-ից քիչ են՝ վերջինը կրկնվում է։ Այդ գույնի համար լուսանկարը **փոխարինում է նկարազարդումը ամենուր** (քարտեր, ապրանքի էջ, զամբյուղ, որոնում)։ Առաջարկվող ձևաչափ՝ 4:5 ուղղահայաց, մինչև 1600px լայնություն, WebP/JPG։

## 6. Ինչպես են աշխատում պատվերները (կարևոր)

Կայքը **backend չունի**, ուստի առցանց վճարում և ավտոմատ ստացում **չկան**։ Ընթացքը՝

1. Հաճախորդը լրացնում է ձևը → ստանում է պատվերի համար (`RN-261105-XXXX`)։
2. Հաստատման էջում մեկ սեղմումով ուղարկում է պատրաստի տեքստը **WhatsApp / Telegram / էլ. փոստով** (կամ պատճենում է)։ Telegram-ի դեպքում տեքստը պատճենվում է և բացվում է չատը՝ պետք է տեղադրել։
3. Դուք ստանում եք հաղորդագրությունը, կապվում հաճախորդի հետ, հաստատում, վճարման հղում ուղարկում (եթե ընտրել է «Առցանց»)։

**Ավտոմատ ստացում ավելացնել.** `config.js`-ում `orderEndpoint`-ում դրեք HTTPS հասցե, որը ընդունում է JSON POST (օրինակ՝ Google Apps Script → Google Sheet, Make, Zapier)։ Այդ դեպքում պատվերը կուղարկվի նաև ավտոմատ։ Նույնը՝ `newsletterEndpoint` բաժանորդագրության համար։

Վճարման համակարգ (Idram, Arca/Ameria/Acba քարտեր, Telcell) **ինտեգրված չէ**. դա բանկի/պրովայդերի պայմանագիր և սերվեր է պահանջում։

## 7. Տեղադրել համացանցում

Սա ստատիկ կայք է, տեղադրվում է ցանկացած ստատիկ հոստինգի վրա (GitHub Pages, Netlify, Cloudflare Pages, ձեր հոստինգ). բավական է բեռնել **ամբողջ թղթապանակի պարունակությունը**։ HTTPS-ը պարտադիր է։ Դոմեյնը կապվում է հոստինգի կարգավորումներից։

## 8. Սահմանափակումներ

- **SEO.** Ապրանքների էջերը JavaScript-ով են գեներացվում (`#/p/carlo`), այդ պատճառով Google-ը դրանք առանձին չի ինդեքսավորի։ Եթե SEO-ն կարևոր է՝ հաջորդ քայլը ապրանքների համար ստատիկ էջեր գեներացնելն է (build-քայլ) կամ Shopify/WooCommerce-ի վրա տեղափոխելը՝ այս դիզայնով։
- Ապրանքների թիվը ձեռքով է (`data.js`)։ Մի քանի տասնյակից ավելի ապրանքի դեպքում արժե տվյալները հանել CMS/աղյուսակից։
- Զամբյուղը/ընտրյալները պահվում են հաճախորդի զննարկչում (`localStorage`), մեկ սարքից մյուսը չեն անցնում։
